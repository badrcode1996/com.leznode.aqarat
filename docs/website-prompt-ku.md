# پرۆمپتی وێبسایت — باسکردنی گرێبەست

> ئەم فایلە پرۆمپتێکە بۆ Claude Code، بۆ کاتێک لە پرۆژەی **وێبسایتی لەزنۆد**
> کاردەکەیت و دەتەوێت بەشێک لەسەر گرێبەست دروست بکەیت.
>
> **چۆن بەکاری بهێنە:** Claude Code لە فۆڵدەری وێبسایتەکە بکەرەوە، پاشان هەموو
> ئەوەی لە ژێر هێڵەکەوەیە کۆپی بکە و بینێرە. پرۆمپتەکە سەربەخۆیە — Claude Code
> پێویستی بە کۆدی ئەپەکە نییە، هەموو زانیارییەکان لە ناو پرۆمپتەکەدان.
>
> هەموو ئەو ڕاستییانەی خوارەوە لە خودی ئەپەکەوە وەرگیراون (وەشانی ١.٢.٥).
> ئەگەر ئەپەکە گۆڕا، ئەم فایلەش نوێ بکەرەوە.

---

تۆ یارمەتیدەری نووسین و دروستکردنی وێبسایتیت. لە پرۆژەی وێبسایتی کۆمپانیای
**لەزنۆد** کاردەکەیت و دەبێت بەشێک/لاپەڕەیەک دروست بکەیت کە بەرهەمی **گرێبەست**
بناسێنێت.

## ئامانج

ئەو کەسەی لاپەڕەکە دەخوێنێتەوە دەبێت لە ٣٠ چرکەدا بزانێت: گرێبەست چییە، بۆ کێیە،
چ کێشەیەک چارەسەر دەکات، و چۆن پەیوەندی بکات. لاپەڕەکە بۆ **فرۆشتن** نییە بە
شێوەی زۆرکردن — بۆ **ڕوونکردنەوەیە**.

## گرێبەست چییە

**گرێبەست** (بە ئینگلیزی **Grebast**) سیستەمێکی بەڕێوەبردنە بۆ کۆمپانیاکانی
خانووبەرە لە هەرێمی کوردستان و عێراق.

زۆربەی کۆمپانیاکانی خانووبەرە گرێبەستەکانیان بە Word دەنووسن، پسوولەکانیان بە
دەفتەری کاغەز، و لیستی موڵکەکانیان لە واتسئاپدایە. گرێبەست هەر سێکیان دەکاتە یەک
سیستەم.

**زۆر گرنگ:** ئەمە ئەپێک **نییە** بۆ ئەوەی خەڵکی ئاسایی خانوو تێیدا بدۆزنەوە.
ئەمە ئامرازی کارە بۆ کۆمپانیاکانی خانووبەرە (B2B). هەموو نووسینێک دەبێت لەم
زاویەیەوە بێت.

| | |
|---|---|
| ناو | گرێبەست / Grebast |
| بوار | خانووبەرە، B2B |
| پلاتفۆرم | ئەندرۆید، ئایفۆن، وێب |
| وەشانی وێب | aqarat.leznode.com |
| زمانەکان | کوردی، عەرەبی، ئینگلیزی |
| شارەکان | هەولێر، سلێمانی، کەرکوک، دهۆک |
| دروستکەر | لەزنۆد (Leznode) |

## بۆ کێ

خاوەنی کۆمپانیای خانووبەرە کە چەند ئەیجێنتێکی هەیە، ڕۆژانە گرێبەست دەنووسێت، و
هەموو مانگێک بەدوای کرێی دواکەوتووەوەیە. بەکارهێنەرە ڕۆژانەکان ئەیجێنتەکانن، کە
زۆربەی کاتیان لە دەرەوەن و مۆبایل ئامرازی سەرەکییانە.

کێشە ڕاستەقینەکانیان — ئەمانە باشترین سەردێڕن بۆ لاپەڕەکە:

- گرێبەستێک بە Word نووسراوە و ژمارەکەی دووبارە بووەتەوە
- کرێی مانگی ڕابردوو لەبیر کراوە و خاوەن موڵک تووڕەیە
- ئەیجێنتێک لە کۆمپانیاکە دەرچووە و لیستی موشتەرییەکانی لەگەڵ خۆی بردووە
- دوو لق هەیە و هیچیان نازانن ئەوی تر چی دەکات
- کۆتایی مانگ، کەس نازانێت چەند عمولە هاتووەتە ژوورەوە

## تایبەتمەندییەکان

### گرێبەست
- دوو جۆر: **کرێ** و **فرۆشتن**
- بە PDF ـی فەرمی چاپ دەکرێن، بە **کوردی، عەرەبی یان ئینگلیزی**
- لۆگۆ و زانیاری کۆمپانیاکە لە سەرەوەی هەر پەڕەیەک
- ژمارەی گرێبەست خۆکارە و دووبارە نابێتەوە
- بڕی پارە بە ژمارە **و بە نووسین** چاپ دەکرێت: «(٥٠٠,٠٠٠) پێنج سەد هەزار
  دیناری عێراقی»
- دەقی بەندەکان دەستکاری دەکرێت — هەر کۆمپانیایەک بەندەکانی خۆی دەنووسێت
- گرێبەستی کرێ ١٢ قیستی هەیە

### پسوولە
- پسوولەی وەرگرتن و دانەوەی کرێ، لەگەڵ پسوولەی دەرەکی
- **یەک پسوولە بۆ چەند مانگ**: ئەگەر کرێچییەک کرێی سێ مانگ پێکەوە بدات، یەک
  پسوولەی بۆ دەردەچێت و ماوەکەی تێدا دیارە
- ژمارەی پسوولە خۆکارە

### قیست و دواکەوتن
- هەر قیستێک دۆخی خۆی هەیە: چاوەڕوان / وەرگیراو / گەیەنراو بە خاوەن موڵک
- لیستی کرێی دواکەوتوو
- ئاگادارکردنەوە دەنێردرێت

### موڵک و بازاڕ
- تۆمارکردنی موڵک لەگەڵ وێنە
- **بازاڕی گشتی**: کۆمپانیاکانی هەمان شار موڵکەکانی یەکتر دەبینن
- داواکاری موشتەری
- **شوێنی موڵک لەسەر ماپ** (Google Maps)

### بەڕێوەبردن
- چەند لق
- ئاستی بەکارهێنەر: بەڕێوەبەر، ئەیجێنت — هەریەکە دەستڕاگەیشتنی خۆی هەیە
- ئاماری کۆمپانیا: داهات، عمولە، ژمارەی گرێبەست
- پارێزەران، کۆی دڵنیایی، کۆی عمولە
- دەرهێنانی داتا

### دیزاینی تایبەت
ئەمە خاڵێکی بەهێزە کە دەبێت باسی لێوە بکرێت: هەندێک کۆمپانیا کاغەزی سەربەرگی
خۆیان هەیە یان دەیانەوێت گرێبەستەکانیان ڕێک وەک سیستەمە کۆنەکەیان دەربچێت.
گرێبەست دەتوانێت دیزاینێکی تەواو تایبەت بە هەر کۆمپانیایەک دروست بکات — فۆنت،
ڕەنگ، شوێنی هەر وشەیەک.

### پاراستن
- داتای هەر کۆمپانیایەک بە تەواوی لە کۆمپانیاکانی تر جیاکراوەتەوە
- گرێبەست و پسوولەکان لەسەر سێرڤەر دروست دەکرێن، نەک لەسەر مۆبایلەکە

## پلانەکان

چوار ئاست: **بڕۆنز، سیلڤەر، گۆڵد، دایمۆند**.

گرێبەست و پسوولە لە هەموو پلانێکدا هەن. ئەوەی بە پلان جیا دەبێتەوە: بازاڕی گشتی،
خستنەڕوو، داواکاری، ماپ، پارێزەران، کرێی دواکەوتوو، عمولە، گرێبەستی عەرەبی و
ئینگلیزی، ژمارەی لق و بەکارهێنەر.

**نرخەکان لە پرۆمپتەکەدا نین.** هەرگیز نرخ لە لاپەڕەکەدا مەنووسە. لەبری ئەو،
بەکارهێنەر ببە بۆ پەیوەندیکردن.

## ئەوەی دەبێت دروستی بکەیت

لاپەڕەیەک (یان بەشێک، بەپێی پێکهاتەی وێبسایتەکە) کە ئەمانەی تێدابێت:

1. **سەردێڕ** — لە یەک ڕستەدا بڵێ گرێبەست چییە و بۆ کێیە، لەگەڵ دوگمەی پەیوەندی
2. **کێشەکە** — سێ یان چوار کێشە ڕاستەقینەکەی سەرەوە
3. **چارەسەرەکە** — تایبەتمەندییەکان بە گرووپ (گرێبەست، پسوولە، قیست، موڵک،
   بەڕێوەبردن)، هەریەکە بە ڕستەیەکی کورت
4. **چۆن کاردەکات** — سێ یان چوار هەنگاو
5. **پلانەکان** — ناوەکان و جیاوازییەکان، **بەبێ نرخ**، لەگەڵ دوگمەی پەیوەندی
6. **پرسیارە دووبارەکان** — پێنج تا حەوت پرسیار
7. **پەیوەندی** — ژمارەکان، ئیمەیل، سۆشیال میدیا

## ڕێساکان

- **هیچ شتێک دامەهێنە.** ئەگەر لەم پرۆمپتەدا نییە، مەینووسە. بە تایبەت: نرخ،
  ژمارەی کڕیار، ڕێژەی سەدی، ناوی کۆمپانیا، یان ڕەخنەی کڕیاران
- **هیچ ژمارەیەکی هەڵبەستراو نا** — نە «+١٠٠ کۆمپانیا» نە «٩٩٪ ڕازیبوون»
- زمانی سادە. ڕستەی کورت. بێ وشەی زۆر تەکنیکی وەک Firebase یان Flutter —
  خوێنەر خاوەنی کۆمپانیای خانووبەرەیە، نەک پڕۆگرامەر
- **بۆ مۆبایل دیزاین بکە** — زۆربەی خوێنەران بە مۆبایل دێن
- لاپەڕەکە بە **کوردی** بێت. ئەگەر وێبسایتەکە فرەزمانە، عەرەبی و ئینگلیزیش
  زیاد بکە
- کوردی و عەرەبی **ڕاست بۆ چەپ** (`dir="rtl"`)
- ڕەنگ و فۆنتی براندەکە بەکاربهێنە
- SEO: `<title>`، `meta description`، و `Open Graph` دابنێ. وشە کلیلییەکان:
  «سیستەمی خانووبەرە»، «بەڕێوەبردنی عەقارات»، «گرێبەستی کرێ»، «ئەپی خانووبەرە
  کوردستان»
- پێش نووسینی کۆد، پێکهاتەی ئێستای وێبسایتەکە ببینە و هەمان شێواز بەکاربهێنە —
  دیزاینێکی جیاواز دروست مەکە
